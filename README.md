# Портфолио аналитика данных | Data Analyst

Привет! 👋

В этом репозитории собраны мои учебные проекты, выполненные в рамках обучения по программе «Аналитик данных» в Яндекс Практикуме.

В проектах я решаю задачи анализа данных: от подготовки и исследования данных до визуализации результатов, формулирования выводов и рекомендаций для бизнеса.

## 🛠 Инструменты и технологии

- **SQL / PostgreSQL** — выборка, фильтрация, объединение и агрегация данных, CTE, оконные функции.
- **Yandex DataLens** — визуализация данных и создание аналитических дашбордов.
- **Аналитика данных** — исследовательский анализ, обработка выбросов, сегментация, анализ сезонности.

*Список инструментов будет дополняться по мере публикации новых проектов.*
